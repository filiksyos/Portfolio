GitToDoc is an experimental tool that transforms Git repositories into documentation links, making it easier to provide context to AI coding assistants. Built with FastAPI, Tailwind CSS, and Jinja2 templating, it simplifies the process of sharing repository information with AI tools.

## Features

- **Repository Processing**: Convert any Git repository into a structured documentation format
- **AI-Friendly Output**: Generate content optimized for AI coding tools like Cursor
- **Token Estimation**: Built-in tiktoken integration for accurate token counting
- **Web Interface**: Clean, responsive interface built with Tailwind CSS
- **Fast Processing**: Powered by FastAPI for quick repository analysis

## Tech Stack

- **Frontend**: Tailwind CSS for modern, responsive design
- **Backend**: FastAPI for high-performance API endpoints
- **Templating**: Jinja2 for dynamic HTML generation
- **Token Processing**: tiktoken for accurate token estimation

This project represents an innovative approach to bridging the gap between version control and AI-assisted development, making repository context more accessible to modern coding workflows.
